ProcessingIndicator SDK

기존 소스 코드 수정 없이 @IndicatorScope 어노테이션과 YAML 설정 파일만으로
네트워크 인디케이터를 자동 제어하는 Android AOP SDK

✓ 소스 무수정 Kotlin 2.0 AGP 8.6 minSdk 24

01개요

OkHttp / HttpURLConnection 네트워크 호출이 발생할 때 화면에 인디케이터(스피너 또는 Lottie 애니메이션)를 자동으로 표시하고, 모든 호출이 완료되면 자동으로 숨깁니다.

기존 코드를 한 줄도 수정할 필요가 없습니다. Gradle 플러그인이 컴파일 타임에 ASM을 통해 바이트코드를 자동 주입합니다.

빌드 설정
build.gradle
→
ASM 바이트코드 주입
컴파일 타임
→
런타임 인터셉터
OkHttp / HttpURL
→
In-App Overlay
자동 표시/숨김

04설치

방법 A — Composite Build (로컬 소스 참조)

SDK 소스를 직접 포함하는 방식. 개발/디버깅에 적합합니다.

프로젝트 구조
MyApp/
├── app/
├── indicator-plugin/          ← SDK 플러그인 소스
│   └── settings.gradle.kts
├── indicator-core/            ← SDK 런타임 소스
└── settings.gradle.kts

방법 B — Maven (배포 버전)

⚠ 준비 중
Maven Central / GitHub Packages 배포는 준비 중입니다. 현재는 Composite Build 방식을 사용하세요.

indicator-plugin/settings.gradle.kts 필수 항목

Composite Build로 포함된 indicator-plugin은 독립적인 Gradle 빌드 컨텍스트에서 실행됩니다. 반드시 자체 settings.gradle.kts가 필요합니다.

indicator-plugin/settings.gradle.kts
rootProject.name = "indicator-plugin"

dependencyResolutionManagement {
    repositoriesMode.set(RepositoriesMode.FAIL_ON_PROJECT_REPOS)
    repositories {
        google()
        mavenCentral()
        gradlePluginPortal()
    }
}
⛔ 없으면 빌드 실패
이 파일 없이 Composite Build를 실행하면 Cannot resolve external dependency ... no repositories are defined 오류가 발생합니다.

05설정 — indicator_config.yaml

src/main/assets/indicator_config.yaml 파일로 인디케이터 동작을 제어합니다. 앱 코드 변경 없이 설정만으로 모든 동작을 조정할 수 있습니다.

전체 예시
indicator:
  timeout: 10000           # 네트워크 응답 없을 시 자동 숨김 대기 시간 (ms)
  overlay:
    blur: false            # 배경 블러 (Android 12+ / API 31+ 전용)
    dim_alpha: 0.5         # 오버레이 배경 어둡기 (0.0 ~ 1.0)
  image:
    type: default          # "default" | "lottie"
    lottie_asset: loading.json  # type: lottie 시 assets 파일명

scopes:
  include:
    - package: com.example.app.api      # 패키지 단위 포함
    - class: com.example.app.SomeClass  # 클래스 단위 포함
  exclude:
    # ⚠ 현재 미구현 — issue #1 참조
    - class: com.example.app.ExcludedClass

설정 항목 레퍼런스

키타입기본값설명
indicator.timeoutInt (ms)10000타임아웃 후 인디케이터 자동 숨김
indicator.overlay.blurBooleanfalse배경 블러 — API 31+ 전용
indicator.overlay.dim_alphaFloat (0~1)0.5반투명 배경 어둡기
indicator.image.typeStringdefaultdefault 또는 lottie
indicator.image.lottie_assetString—type=lottie 시 assets 폴더 내 파일명
scopes.includeList—인터셉터 주입 대상 (package: 또는 class:)
scopes.excludeList—주입 제외 대상 ⚠ 미구현

06동작 원리

컴파일 타임 — ASM 바이트코드 주입

Gradle 플러그인(com.jini.indicator)이 AGP의 AsmClassVisitorFactory를 통해 컴파일된 클래스 파일을 순회합니다. scopes.include에 해당하는 클래스의 OkHttpClient 빌드 코드와 HttpURLConnection 호출을 찾아 자동으로 인터셉터를 주입합니다.

주입 전/후 (개념)
// 원본 코드 (개발자가 작성한 그대로)
val client = OkHttpClient.Builder().build()

// 컴파일 후 바이트코드 (SDK가 자동 주입)
val client = OkHttpClient.Builder()
    .addInterceptor(IndicatorOkHttpInterceptor.getInstance())
    .build()

런타임 — 자동 초기화

IndicatorContentProvider가 앱 시작 시 자동으로 SDK를 초기화합니다. 별도의 Application.onCreate() 코드가 필요 없습니다.

In-App Overlay — 인디케이터 표시

ActivityLifecycleCallbacks로 현재 활성 Activity를 추적하고, 네트워크 호출 시 해당 Activity의 Window 위에 오버레이를 표시합니다. WindowManager나 SYSTEM_ALERT_WINDOW 퍼미션 없이 동작합니다.

동시 호출 추적 — AtomicInteger Depth Counter

동시 호출 처리 로직 (개념)
// 네트워크 요청 시작
depth.incrementAndGet()  // depth = 1, 2, 3...
showIndicator()

// 네트워크 요청 완료
val remaining = depth.decrementAndGet()
if (remaining <= 0) {
    depth.set(0)         // 클램프 (음수 방지)
    hideIndicator()
}

3개의 동시 요청이 있을 때 depth는 3이 되고, 각 요청이 완료될 때마다 감소합니다. 마지막 요청이 완료되면 인디케이터가 숨겨집니다.

07커스텀 렌더러

기본 렌더러 (DefaultSpinnerRenderer)

Lottie 의존성 없이 기본 스피너를 표시합니다. indicator_config.yaml에서 type: default로 설정합니다.

Lottie 렌더러

Lottie 파일(.json)을 애니메이션으로 표시합니다.

설정
indicator:
  image:
    type: lottie
    lottie_asset: my_loading.json  # src/main/assets/my_loading.json
ℹ 폴백
lottie로 설정했더라도 앱에 Lottie 의존성이 없으면 자동으로 DefaultSpinnerRenderer로 폴백합니다.

08문제 해결

Plugin not found: 'com.jini.indicator'

확인 사항
// settings.gradle.kts — includeBuild가 pluginManagement 블록 안에 있어야 합니다
pluginManagement {
    includeBuild("indicator-plugin")  // ← 이 위치가 맞습니다
    repositories { ... }
}

// ❌ 잘못된 위치 (pluginManagement 밖)
includeBuild("indicator-plugin")  // 플러그인 미인식

Cannot resolve external dependency (no repositories)

indicator-plugin/settings.gradle.kts가 없거나 repositories 블록이 없는 경우입니다.

indicator-plugin/settings.gradle.kts 필수
rootProject.name = "indicator-plugin"

dependencyResolutionManagement {
    repositories {
        google(); mavenCentral(); gradlePluginPortal()
    }
}

인디케이터가 표시되지 않음

빌드 로그에서 플러그인 적용 여부를 확인합니다:

terminal
./gradlew :app:assembleDebug --info 2>&1 | grep "\[IndicatorPlugin\]"

# 정상: [IndicatorPlugin] AndroidComponentsExtension found, registering instrumentation
# 문제: [IndicatorPlugin] AndroidComponentsExtension NOT found
#   → AGP 버전 확인: compileOnly("com.android.tools.build:gradle:X.X.X") 버전이 맞아야 합니다

네트워크 호출은 있는데 인디케이터가 뜨지 않음

scopes.include의 패키지명이 실제 네트워크 호출 클래스의 패키지와 일치하는지 확인합니다. 패키지명은 정확히 일치해야 합니다 (prefix 매칭).

09알려진 제한사항

#1
compile-time scope exclusion 미구현
scopes.exclude 설정이 현재 적용되지 않습니다. ProguardRuleGenerator와 IndicatorClassVisitorFactory.isInstrumentable()에서 YAML exclude 항목을 참조하지 않아 모든 include 대상 클래스에 주입됩니다.
#2
테스트 앱 CoroutineScope 취소 경로 없음
sample 시나리오 클래스들이 Activity 라이프사이클과 무관한 Scope를 사용합니다. 실제 프로덕션 앱에서는 ViewModel이나 Activity의 lifecycleScope 사용을 권장합니다.
#4
overlay.blur — API 31+ (Android 12+) 전용
indicator.overlay.blur: true는 Android 12 이상에서만 동작합니다. minSdk 24 기기에서는 이 옵션을 false로 설정하세요.
